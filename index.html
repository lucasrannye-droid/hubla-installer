🚀 Squad Hubla Migrador v2.0

Guia de Instalação

Configure tudo do zero e rode migrações automáticas de áreas de membros para a Hubla.

💻
Plataformas suportadas: macOS 12+ e Windows 10/11.
Linux não é suportado.

No Mac o setup é zero-click (lê credenciais do Chrome via Keychain). No Windows o setup pede 2 cookies via F12 (Chrome v127+ bloqueia leitura externa). Mesmo prompt no Claude, mesmo fluxo geral nos dois.

Problemas Comuns
Soluções rápidas para os erros mais frequentes
▶ ⛔ "Token expirado" ou erro 403

O squad renova o token automaticamente. Se persistir, re-clique no link mágico do cliente no navegador e tente novamente.

▶ 🐌 Upload muito lento

Normal para vídeos grandes (lives de 2-4GB). O squad usa 3 workers paralelos para acelerar. Uma migração de 150+ vídeos leva em torno de 1-2 horas.

▶ 🔒 "Acesso negado ao repo" no GitHub

Você logou no GitHub mas ainda não foi adicionado como colaborador do repo privado. Copie a mensagem que o instalador mostra (com seu usuário do GitHub) e mande no Slack pro Lucas adicionar você.

▶ 🍪 "device_data não encontrado" no Chrome

O Chrome precisa estar logado em app.hub.la com a conta do produtor de destino (não sua conta de analista). Faça login no Chrome e rode python3 scripts/setup_doctor.py dentro da pasta do migrador.

▶ 🔁 Algo travou no meio — posso rodar de novo?

Sim. O bootstrap é idempotente — rode o mesmo curl ... bootstrap.sh | bash. Cada passo detecta se já foi feito e pula.

▶ 🔑 "Claude Code precisa de assinatura"

O Claude Code requer plano Pro ($20/mês), Max ou Teams. O plano gratuito do Claude não inclui acesso ao Claude Code.
